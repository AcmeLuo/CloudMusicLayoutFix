# CloudMusicLayoutFix

网易云音乐 PC 版在副屏上会把界面画歪：窗口右边的元素被整个裁掉，能看见的按钮点不到。客户端给界面写死了一个 1056px 的宽度，屏幕比这窄的时候（比如 4K 竖屏开 200% 缩放、1080p 竖屏开 125%），超出去的部分就被裁掉了。

这个工具不动客户端文件。它只是让客户端带着本机调试端口启动，连上去往页面里补一段 CSS，把那些写死的宽度放开。只在启动那一瞬间工作，不留常驻进程。

![修复前后对比](assets/preview.svg)

## 什么时候会出问题

屏幕的「物理宽度 ÷ 显示缩放」小于 1056 就会触发：1080×1920 @125%（可用 864）和 1600×2560 @200%（可用 800）都中招，我这两块竖屏副屏每次都能复现。

原生客户端在副屏上长这样：

- 右上角的最小化 / 最大化 / 关闭按钮被挤出窗口，看不见也点不到
- 歌单里「时长」整列落在屏幕外，行尾的操作按钮贴着屏幕边缘
- 设置页顶部的设置项排到屏幕外，后面的选项点不到
- 播放栏的 喜欢 / 评论 被歌名区一路推向中间那排控制键，窗口再窄一点就直接压上去

主屏（1707 CSS px）上一切正常。

## 用法

1. 下载 [CloudMusicLayoutFix.exe](https://github.com/AcmeLuo/CloudMusicLayoutFix/releases/latest)（35 KB，免安装，不需要 Node.js）
2. 右键托盘图标，完全退出网易云音乐
3. 双击运行，选「是」，允许管理员权限

程序会把自己装进客户端目录顶替 `cloudmusic.exe`，官方原文件改名成 `cloudmusic.real.exe`。之后不管从开始菜单、任务栏还是双击图标打开，都会自动应用；它只在客户端启动的那一瞬间工作，没有常驻进程，也没有托盘图标。

想回到官方版本，运行 `CloudMusicLayoutFix.exe --restore`。

另外几个参数：

| 参数 | 作用 |
| --- | --- |
| `--install` | 直接安装，不弹询问框 |
| `--restore` | 还原官方 `cloudmusic.exe` |
| `--once` | 只注入一次，不改任何文件 |
| `--tray` | 常驻托盘，客户端每次启动都重新注入，页面重载也不掉 |

## 它是怎么做的

客户端的前端打包在加密容器里，磁盘上没有明文，改不了。但它是 CEF 应用，接受 `--remote-debugging-port`，所以启动时带上端口，用 DevTools 协议连进去往页面塞一段样式表：

```css
[class*='RightContainer'] { flex: 1 1 0 !important; min-width: 0 !important; }  /* 主内容区允许收缩 */
[class*='HeaderRow']      { display: flex !important; }                         /* 标题栏 grid 改 flex */
[class*='IconBar']        { flex: 0 0 auto !important; }                        /* 窗口按钮永远完整 */
```

只放开约束，不改字号和控件尺寸，所以界面保持系统缩放该有的大小。屏幕够宽的时候（比如我的主屏）这些规则完全不生效，元素坐标和原生一模一样。

完整样式表在 [css/layout-fix.css](css/layout-fix.css)，根因、逐界面审计结果和构建方式在 [docs/TECHNICAL.md](docs/TECHNICAL.md)。

## 常见问题

**我是搜「网易云音乐副屏显示不全」「关闭按钮点不到」找过来的，是这个吗？**
多半就是。判断方法：把客户端拖到副屏后右上角的窗口按钮消失、或者歌单少了一列，而拖回主屏就正常——那就是界面的最小宽度比屏幕宽，被裁掉了。

**装完没效果？**
先看日志 `%LOCALAPPDATA%\CloudMusicLayoutFix\layout-injector.log`，正常会有一行 `inject applied vw=… dpr=… closeVisible=true`。如果写的是 `closeVisible=false`，说明客户端改了界面类名（大版本更新），把日志发我一下。

**客户端更新后会失效吗？**
小版本不会：样式按类名前缀匹配（`Content_`、`HeaderRow` 这种），不带每次构建都会变的哈希后缀。要是更新把 `cloudmusic.exe` 换掉了，重新运行一次本程序即可。

**网易云装在别的盘或别的目录怎么办？**
会自动找：`--app` 指定 → 程序旁边 → 正在运行的客户端进程 → 注册表卸载项 → 常见路径 → 浅层扫描，日志里会写这次是哪种方式找到的。也可以自己指定：`CloudMusicLayoutFix.exe --app "D:\你的路径\cloudmusic.exe"`。

**安全吗？**
不碰音频，不绕过任何授权或付费功能。唯一动到的客户端文件就是 `cloudmusic.exe` 本身（备份为 `cloudmusic.real.exe`），调试端口只监听 127.0.0.1。

**会不会把界面缩小？**
不会。这和 `--force-device-scale-factor=1` 那类做法不一样，界面还是系统缩放该有的大小。

**窄屏上会变挤吗？**
会收窄两个地方：搜索框，和播放栏的歌名（省略号截断）。收的正是原来溢出被裁掉的那点宽度。

**杀毒软件报毒或提示风险？**
这个 35 KB 的 exe 没有代码签名证书，又要请求管理员权限，被杀软误报很正常。仓库里就是完整源码（`src/CloudMusicLayoutFix.cs`），可以自己跑一次 `build-exe.cmd` 编译一个，或者把它加进信任列表。
